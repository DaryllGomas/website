SENTINEL Accounts Watch

Privacy policy · updated 2026-11-17

SENTINEL Accounts Watch is a private tool. It runs on one home server and is used only by its owner, Daryll Gomas, on his own Google accounts. It is not offered to anyone else.

What it reads

With the account owner's permission, it reads Gmail messages read-only, to spot security alerts (sign-in codes, password and account changes, bank alerts) and warn the owner about attacks on his accounts.

What it never does

  • It never sends, deletes, labels or changes any email.
  • It never shares, sells or transfers Gmail data to anyone, and never uses it for advertising.
  • It never uses Gmail data to train AI models. Messages are judged by fixed rules, not by AI.

Where the data stays

Anything it records stays on the owner's home server. Only the owner can see it.

Turning it off

Access can be removed at any time in the Google account, under Security → Third-party connections.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
