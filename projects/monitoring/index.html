01The problem

More alerts is not more safety.

One person runs a small server room: a virtualization host with four VMs, a segmented network, a GPU node, a backup NAS, and a market-data platform that has to stay up around the clock. All of it needs watching, and so does the internet link.

The usual answer is more detection and a heavier security suite. But a monitor that pages you for everything trains you to ignore it.

Success isn't detecting more things. It's noticing the few things a person would want to know, explaining them correctly, and staying silent the rest of the time.

02What I built

One quiet appliance that watches everything.

SENTINEL is a low-power observability appliance (about 20 containers on the box, with its control plane, as of Oct 2026) that collects metrics, logs, network flows and health probes from every machine and service, then decides what is worth a person's attention.

  • Raw alerts are correlated into one incident with the evidence attached, sent to my phone.
  • Security checks flag new devices, failed or unusual logins, new accounts, file-integrity changes, pending updates and newly opened ports.
  • Public web addresses are probed by their public names, and the internet link itself is measured.
  • A dead-man check on two other machines watches the watcher, so a silent SENTINEL is never mistaken for a healthy one.
03How it works

Signals in, one clear answer out.

Watches

  • Servers and VMs: CPU, memory, disks
  • Gateway, switch and Wi-Fi access points
  • Every service: is it up, and is it right?
  • The internet link
  • Logins, accounts and file changes

Listens

  • Metrics over time (Prometheus)
  • Network flow and SNMP: who talks to whom
  • Disk health and service probes, inside and by public name
  • Searchable log history (Loki)

Decides

  • Alert rules for every machine, service and the internet link
  • Raw alerts become one incident
  • The evidence is attached to it

Delivers

  • One clear alert, with evidence, to my phone
  • Dashboards: everything at a glance (Grafana)
  • Silence, when all is well

06How it's tested and run

Tested, not trusted.

  1. The alarm was tested before it shippedA 19-case scenario test of the dead-man alarm passed before deploy, then an independent AI reviewer checked it twice.
  2. The watcher is watchedA dead-man check on two other machines alerts if SENTINEL itself goes quiet.
  3. Probes by public namePublic web addresses are also checked by their public names, not only by their inside addresses.
  4. Built with AI, operated with guardrailsAI tools write the code; I own the requirements, the verification and the operations. Agents inspect read-only first, and every change is logged with how to reverse it.
